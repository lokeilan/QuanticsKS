# 一维计算流程

网格为周期均匀网格，原子单位。轨道核心保存 `u_j=√h ψ(x_j)`，因此欧氏内积对应空间积分，密度由 `Σᵢ fᵢ|uᵢ|²/h` 得到。QTT 核的物理维度是二，按低有效位到高有效位编码。

## SCF

1. 构造静态外势、相互作用核、离散移位和 XC 表，准备归一化初态。
2. 从当前轨道拟合密度并混合。混合残差保留为原核的线性表达式；仅在 Hartree 消费者需要独立核时物化。
3. 固定本轮混合密度，复用 Hartree 与局域势采样，进入 LRRAP 轨道更新。
4. L1 计算 Rayleigh 值与残差；L2 建立规范框架；L3 投影轨道、预条件残差和历史方向。
5. L4 对共同坐标做 SVD 并构建约化 H；L5 求解受正交约束的系数；L6 重构轨道和必要历史方向；L7 按原规则执行正交化及 Ritz。
6. 按已有排程执行 Green polish。它会丢弃历史方向，因此不再构造或压缩随后必然丢弃的历史。
7. 压缩到保存精度，重新计算输出密度与总能量，记录相邻能量变化。达到配置停止条件或迭代上限后，对输出态做独立物理审计。

## 构建、秩和规范

TCI 使用 prrLU 自适应采样构建。现有后置 SVD 按 `tolerance * post_rounding_factor` 控制秩和舍入，并形成消费者所需的规范。直接消费该输出的 Green MPO 不再重复输入 QR；一般未知规范输入仍在 MPO 入口准备所需规范。

L4 的 SVD 方向来自已投影坐标，满足既有切空间规范约束。`h_project_tangent` 因而直接使用这些坐标，省去对重建切向量的恒等投影；一般轨道继续使用 `h_project`。

不对每个构建输出机械增加全链 SVD。构建、秩控制、规范准备和后续消费者的要求分别承担各自职责。TCI 局部 pivot 误差不能当作全局 L2 或物理残差。

## 内积与并行

`inner` 根据实际 bond profile 选择直接循环或原 TCI/BLAS 路径。较大的直接收缩在一个 site 内按独立输出行并行，保持单个输出元素的求和顺序；site 间递推保持顺序。任务使用各自的中间缓冲区，外层轨道/Gram 任务内不再内部拆分。

当前门槛要求单 site 工作量 `p*ry*ox*(rx+oy)` 至少为 `4*40^3`，可并行部分累计至少为其四倍。较小收缩保留原串行循环，避免调度开销超过收益。单次内积通过 `QuanticsKS.Q.inner(x,y; cfg=(;parallel_tasks=0))` 配置；SCF 沿用现有并发选项。

固定势 `fixed_spectrum` 复用相同张量、投影和算符；实时传播使用对称势能半步、Cayley 动能整步、势能半步，按更新后的密度反馈势。两者各自记录停止或完成含义。
